# Python Calculator (Tkinter)

A GUI Calculator built with Python and Tkinter - my first public Python project.

## Features

- Standard Operations: Addition, Subtraction, Multiplication, Division
- Percentage and Power
- Backspace and All Clear
- Custom Dark Theme with Accent Styling
- Click Sound Feedback (Non-Blocking, via Threading)
- Handles Edge Cases like Leading Zeroes

## What I learned

- GUI Layout with Tkinter's grid system
- Using '//' and '%' to calculate grid positions dynamically
- String slicing to isolate parts of the user input (for the '%' feature)
- Why 'eval()' needs careful handling
- Avoiding UI freezes using threading
- Debugging errors

## Built with

- Python
- Tkinter
